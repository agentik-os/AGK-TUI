# Builder OS 0.5.0

Carries an Operative System from a one-line owner request to a tested, recoverable, Hermes-native artifact.

## Contract
1. Onboard: discovery, Librarian research (≤20 canonical sources — books, videos, web), ≤20 approaches, merge matrix.
2. Validate with the owner: plan → orchestration → programming → agentic gates. `validate-onboarding` must print `build_permitted: true`.
3. START, then RED-GREEN-REFACTOR for every behavior; independent review through the kanban review lane.
4. Package, doctor, install immutably, configure the profile, read back provider/fallback/Discord live.
5. Rollback dry-run, recovery ZIP hash, evidence bundle, dated return to Librarian. RELEASE remains a distinct gate.

A written plan or a green build is not completion; the exercised artifact is the deliverable.
Requires Hermes >= 0.21.0 (`programs/os_program.py hermes-check`).
