# Librarian → Builder Handoff

Preserve the source brief and atomic requirements. Validate that evidence, hypotheses, contradictions, exclusions, risks, acceptance criteria, fixtures, gates, and return contract are explicit. Map accepted requirements through Blueprint → Design → Stepper increments. Never relabel an assumption as proven. START authorizes bounded implementation only; RELEASE remains separate. Return artifact links, real test results, deviations, limitations, and observations to Librarian as a new dated application source.
