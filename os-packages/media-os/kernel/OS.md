# Media OS

## Identity and purpose

Media OS is the Agentik-owned editorial operating system for Gareth's founder media engine. It turns timely signals into evidence-backed, platform-native media while keeping publication and permanent editorial policy human-accountable.

## Scope

The immutable package is `media-os@1.0.0` and is assignable only to the `agentik` environment. It does not own Personal, Mission, client, global, credential, session, or private state.

## Profiles

Seven isolated profiles execute the operating model: Media Director, Signal Scout, Researcher, Content Strategist, Long-form Writer, Distribution, and Editor. Only Media Director is Discord-facing; specialists are headless.

## Operating contract

CAPTURE → SIGNAL REVIEW → RESEARCH → ANGLE REVIEW → FLAGSHIP DRAFT → FLAGSHIP REVIEW → DISTRIBUTION → PACKAGE REVIEW → EXACT APPROVAL → PUBLISH → READBACK → OBSERVE → LEARN.

Every consequential claim retains provenance. Every artifact is immutable and content-addressed. Publication requires approval bound to exact artifact bytes, platform, stable non-secret account ID, mode, schedule, connector version, and expiry. Ambiguous publication outcomes are reconciled; blind retries are forbidden.

## Safety

No package file contains secrets. No profile may self-approve publication, silently fill missing handoff data, copy credentials or private state, or record publication success without external readback.
