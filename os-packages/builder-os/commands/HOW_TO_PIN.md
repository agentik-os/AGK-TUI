# builder-os Discord command pin

Pin a short owner-authored message in the dedicated `builder-os` channel (bot **Build OS**):
mention the bot in a new thread to wake it; `/panel` opens the control surface, `/clear` starts a
fresh session, `/settings` is the third bounded action. Hermes built-ins `/plan`, `/goal`, `/btw`,
`/bg`, `/kanban`, `/rollback` work in the gateway. Application creation, OAuth, privileged intents,
and the reusable token remain owner-controlled (secure input only, never chat).
